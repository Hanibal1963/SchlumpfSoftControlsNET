# SchlumpfSoftControlsNET

Eine Sammlung verschiedener Controls.

Diese Sammlung ist die NET Ausgabe der SchlumpfSoft Controls.

Es wurden gegenüber der vorherigen Versionen einige Änderungen vorgenommen und neue Controls hinzugefügt sowie die Struktur geändert.

> &#x26A0; **Hinweis**
>
> *Die beiden ersten Versionen sind mittlerweile nicht mehr im Marketplace verfügbar.*
>
> *Die Codes wurden archiviert:*
>
> [Version 1.](https://github.com/Hanibal1963/SchlumpfSoftControls)
>
> [Version 2.](https://github.com/Hanibal1963/SchlumpfSoftControls2)
>
> Die [3.Version](https://github.com/Hanibal1963/SchlumpfSoftControls3) ist weiterhin verfügbar, wird allerdings nicht mehr gepflegt.

## Die Sammlung enthält aktuell folgende Controls

- **[AniGifControl](SchlumpfSoftControlsNET/AniGifControl/AniGifControl.md)** - Ein Control zum Anzeigen von animierten GIF - Grafiken.
- **[ColorProgressBarControl](SchlumpfSoftControlsNET/Doc/ColorProgressBarControl.md)** - Ein Control zum Anzeigen eines anpassbaren Fortschrittsbalkens mit verschiedenen Farben.
- **[DriveWatcherControl](SchlumpfSoftControlsNET/Doc/DriveWatcherControl.md)** - Ein Control zum Überwachen von Laufwerken und Anzeigen von Informationen über diese.
- **[ExplorerTreeViewControl](SchlumpfSoftControlsNET/Doc/ExplorerTreeViewControl.md)** - Ein Control zum Anzeigen und Navigieren der Windows Verzeichnisstruktur (ähnlich dem linken Bereich des Windows Explorers).
- **[ExtendedRTFControl](SchlumpfSoftControlsNET/Doc/ExtendedRTFControl.md)** - Ein Control zum Anzeigen von Rich Text Format (RTF) Inhalten mit erweiterten Funktionen.
- **[FileListControl](SchlumpfSoftControlsNET/Doc/FileListControl.md)** - Ein Control zum Anzeigen von Dateien in einer Liste mit verschiedenen Ansichten und Funktionen.
- **[IniFileControl](SchlumpfSoftControlsNET/Doc/IniFileControl.md)** - Ein Control zum Anzeigen und Bearbeiten von INI-Dateien mit einer benutzerfreundlichen Oberfläche.
- **[NotifyFormControl](SchlumpfSoftControlsNET/Doc/NotifyFormControl.md)** - Ein Control zum Erstellen von Benachrichtigungsformularen, die über der Taskleiste oder anderen Anwendungen angezeigt werden können.
- **[SevenSegmentControl](SchlumpfSoftControlsNET/Doc/SevenSegmentControl.md)** - Ein Control zum Anzeigen von Zahlen im Sieben-Segment-Stil, ähnlich wie bei digitalen Anzeigen.
- **[ShapeControl](SchlumpfSoftControlsNET/Doc/ShapeControl.md)** - Ein Control zum Zeichnen von verschiedenen geometrischen Formen wie Rechtecken, Ellipsen, Linien usw.
- **[TransparentLabelControl](SchlumpfSoftControlsNET/Doc/TransparentLabelControl.md)** - Ein Control zum Anzeigen von transparenten Texten über anderen Steuerelementen oder Hintergründen.
- **[WizardControl](SchlumpfSoftControlsNET/Doc/WizardControl.md)** - Ein Control zum Erstellen von mehrseitigen Assistenten (Wizards) mit benutzerdefinierten Seiten und Navigation.
- **[ImageComboBoxControl](SchlumpfSoftControlsNET/Doc/ImageComboBoxControl.md)** - Ein Control zum Anzeigen einer Combobox mit Symbolen.
- **[PasswordControl](SchlumpfSoftControlsNET/Doc/PasswordControl.md)** - Ein Control zum Eingeben und Validieren von Passwörtern.
